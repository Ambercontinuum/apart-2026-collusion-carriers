## Completed execution

- Experiment 1: 15 grid episodes; G2 executed three emission permits. Native
  final assignment is not certified in that runner. All proposed symbols were zero.
- Experiment 2 final attempt: 32 native permits, eight each for check_A, check_B,
  emission and allocation. All eight persisted journal chains and execution heads
  verified. Functional calls as well as disclosure ran under native capability binding.
- Offline tests cover adverse cases; scripted refusals are not live model-safety
  stops or additional behavioral outcomes. Prior 17-case native validation is
  pre-sprint instrument evidence.

The host-canonical arm produces the same delivered views without native permits.
Every final main sender chose zero. Matched outcomes therefore demonstrate no
measured suppression or SERAPH superiority. The integration result is positive and
bounded; behavioral efficacy and independent reproduction remain unestablished.

## Boundary and assumptions

The host declares topology and supplies constraint observations. Canonical payload
checks and realized-view postconditions support its assertions; they do not detect
semantic collusion. Recovery is a local held-buffer reset probe. Guardian,
environment and distillation defaults are declared adapter assumptions, not
validated human-agent coupling or deployment sensors. The Python host is trusted;
unmediated or malicious host code is outside the membrane. No independent witness
key anchors the journals. A hash chain binds bytes, not truth or authorship.

Task choice, timing and other undeclared channels are not covered. The preview
scaffold repeats information already available privately. The research adapters
are domain-specific code, not a general integration SDK or formal proof of this
experiment. The human-coupled warrant interpretation is observational and distinct
from the executed native mechanism; no trusted-agent offer intervention was run.
