## Template guidance

- Title, author names and affiliations; sprint attribution footnote.
- Abstract: 150–250 words covering problem, approach, results and takeaway;
  polish after the results are final.
- Suggested sections: Introduction; Related Work; Methods; Results;
  Discussion and Limitations (including Future Work); Conclusion.
- Code and Data links; optional Author Contributions; References;
  optional supplementary Appendix; LLM Usage Statement when assistance was used.
- Methods should support replication and justify choices. Results distinguish
  observations from interpretations and discuss robustness and sample limits.
- At least one figure is strongly encouraged. Number figures and tables, use
  descriptive captions, position near first reference, and keep labels legible.
- Remove all placeholder guidance before submission. Section organization is
  adaptable. References use a consistent format with URLs or DOIs where available.

## Relationship to the frozen project plan

The template recommends four pages excluding references and appendix. It does
not itself state an eight-page hard cap. The supplied frozen v3.1 plan specifies
4–8 pages and a required Limitations and Dual-Use / Ethical Considerations
appendix. Retain these project requirements; do not present them as quoted
template instructions. The template additionally includes an LLM Usage Statement.
